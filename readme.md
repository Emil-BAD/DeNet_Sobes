# DeNet\_task — Инструмент для анализа токенов на Polygon

**DeNet\_task** — это инструмент для анализа токенов на блокчейне Polygon. Проект разработан с упором на модульность, масштабируемость и практическую ценность как для образовательных задач.

## Функционал

- **Получение информации о токене**

  - Название, символ, количество десятичных знаков
  - Общее количество токенов (если доступно)

- **История трансферов**

  - Быстрое получение истории транзакций по адресу
  - Использование индексированного API для высокой производительности

- **Удобный вывод данных**

  - Цветные таблицы для наглядного анализа

- **Получение балансов**

  - Баланс по одному адресу
  - Баланс по списку адресов (batch-режим)

- **Топ держателей с анализом**

  - Получение топ-N держателей токена
  - Последний трансфер для каждого держателя

- **Поддержка запуска через**

  - Возможность использовать функциональность напрямую через `main.py`
  - Гибкий ввод токенов через `.env` или аргументы

## Используемые технологии и API

- **Moralis API**

  - Быстрый доступ к индексированным данным (трансферы, владельцы)
  - Идеально подходит для работы с большим объемом данных

- **Web3.py**

  - Взаимодействие с контрактами токенов
  - Используется в базовых запросах (название, символ и т.д.)

## Установка и запуск

1. Установите зависимости:

   ```bash
   pip install requests web3 dotenv tabulate colorama pydantic --upgrade
   ```

2. Создайте файл `.env` с переменными:

   ```env
   MORALIS_API_KEY=ваш_ключ_от_moralis
   TOKEN_ADDRESS=0x1a9b54a3075119f1546c52ca0940551a6ce5d2d0
   ```

3. Запустите основной скрипт:

   ```bash
   python main_moralis.py
   ```

   Или используйте `main.py` для кастомных операций:

   ```bash
   python main.py
   ```

## Легкость адаптации

- Быстрая интеграция с **FastAPI**:
  - `/api/token-info` — информация о токене
  - `/api/transfers/{address}` — история трансферов
- JSON-вывод и развёртывание REST API займут минимум времени

## Возможности для расширения
- Поддержка ручного ввода аргументов командной строки
- Поддержка нескольких сетей (Ethereum, BSC и др.)
- Реальные уведомления о трансферах через WebSocket
- Создание полноценного микросервиса на FastAPI

## Авторское слово

Этот проект яв-ся заданием собеседования в DeNet. Внедрение FastAPI откроет двери к созданию микросервисов и API для Web3-продуктов.
